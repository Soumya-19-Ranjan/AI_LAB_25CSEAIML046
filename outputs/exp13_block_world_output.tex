\subsection*{Experiment 13: Blocks World Problem}
\textbf{Script File:} \texttt{block_world.py} \\[4pt]
\textbf{Aim:} To solve the Blocks World planning problem using state-space BFS search to transition from initial block stacks to goal configuration. \\[4pt]
\textbf{Sample Input:} 3 blocks (A, B, C); Initial: A on Table, B on A, C on Table; Goal: A on Table, B on Table, C on B \\[6pt]
\begin{tcolorbox}[colback=black!5!white,colframe=black!75!white,title=Terminal Execution Output - Blocks World Problem]
\begin{verbatim}
===== BLOCK WORLD PROBLEM =====
Enter number of blocks: 
Enter block names:
Block 1: Block 2: Block 3: 
===== INITIAL STATE =====
Enter the position of each block.
Enter 'Table' if the block is on the table.
Where is A initially? Where is B initially? Where is C initially? 
===== GOAL STATE =====
Enter the desired position of each block.
Where should A be in the goal state? Where should B be in the goal state? Where should C be in the goal state? 
Initial State:
A -> Table
B -> A
C -> Table

Goal State:
A -> Table
B -> Table
C -> B

===== SOLUTION =====
Step 1: Move B from A to Table
Step 2: Move C from Table to B

Total moves: 2
\end{verbatim}
\end{tcolorbox}
